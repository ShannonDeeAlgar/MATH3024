# MATH3024 Reader

Each weekly topic is explored through one or more canonical models across three connected resources. Lectures establish the phenomenon and questions, the Reader develops the durable explanation, and workshops make the modelling logic executable so that you can test its assumptions and behaviour.

- **Unit essentials, announcements, assessment, and weekly resource links:** LMS
- **Reader:** this site
- **Lecture slides:** use the clearly labelled **Lecture slides** child beneath each week
- **Workshop notebooks:** open the weekly **Workshop** page and choose **Download** at the top of the page, then select the `.ipynb` file. It is generated from the same notebook used to build the Reader.

Start with [Welcome to MATH3024](notebooks/week00/Getting_Started.ipynb) for the modelling process, notebook setup, and guidance on code and pseudocode. The [Glossary](glossary.md) collects the shared vocabulary used across topics.
