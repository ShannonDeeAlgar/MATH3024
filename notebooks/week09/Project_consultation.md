# Project consultation

Use this session to discuss your project.

The [optional notebook](WS_Information_theory.ipynb) is for projects that estimate probabilities from categorical observations or use entropy. It shows how probability and entropy estimates depend on the definition of an outcome and the sample size.

No notebook completion or submission is required.

Before using an information measure, decide

- What question will it answer?
- What is one observation?
- Which outcomes and probabilities define the distribution?
- What spatial or temporal unit will you use?
- What conclusions cannot be drawn from the result?
